# Proof of Work

This catalog distinguishes a learning claim from the evidence supporting it. Private
evidence is not presented as publicly reproducible proof; it is marked honestly until
a reviewed public artifact exists.

## Evidence levels

| Level | Meaning |
| --- | --- |
| Planned | The outcome and acceptance criteria are defined |
| Private evidence | The work exists but is still behind a publication gate |
| Public summary | A sanitized explanation is available publicly |
| Public reproducible | Source, setup, and validation are publicly reviewable |

## Entry format for future evidence

Each new public entry should answer:

1. What problem was addressed?
2. What was created or changed?
3. What evidence can another person inspect?
4. What failed or remained uncertain?
5. What security or privacy boundary was checked?
6. What can now be done independently?
7. What is the next stronger proof?

This format is deliberately stricter than a chronological “today I learned” log. It
keeps the catalog useful and prevents activity from being confused with progress.
